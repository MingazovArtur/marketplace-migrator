# 🚀 Marketplace Migrator v2.1

Универсальный инструмент для автоматической миграции карточек товаров между маркетплейсами (**Ozon**, **Wildberries**, **Яндекс Маркет**). 

Позволяет селлерам экономить часы ручной работы, автоматически перенося названия, описания, цены, фотографии и интеллектуально маппя категории между разными площадками.

> 💡 **Особенность:** Полностью функциональный MVP, который работает **без реальных API-ключей** благодаря умному Mock-режиму. Идеально для демонстрации архитектуры, логики и проведения тестов.

---

## ✨ Основные возможности (v2.1)

- 🌍 **Мультиплатформенность:** Поддержка импорта и экспорта для Ozon, Wildberries и Яндекс Маркета.
- 🧠 **Умный маппинг категорий:** Автоматическое преобразование категорий (например, Ozon *"Дом и сад / Уборка"* → WB *"Товары для дома"*) на основе эвристики и локальных справочников.
- 📸 **Работа с медиа:** Сервис для скачивания фотографий товаров с генерацией красивых заглушек для тестового режима.
- 🛡️ **Валидация и защита:** Проверка форматов ключей на фронтенде и бэкенде. Защита от переноса товара на ту же платформу.
- 🎨 **Современный UI:** Интуитивно понятный светлый интерфейс на React с цветовым кодированием платформ, модальными окнами и уведомлениями.
- 🏗️ **Чистая архитектура:** Использование паттернов Repository, Factory и разделение на роутеры для легкой масштабируемости.
- 🐳 **Docker:** Полная контейнеризация для запуска одной командой в любом окружении.

## 🛠️ Технологический стек

| Слой | Технологии |
|------|------------|
| **Frontend** | React 19, Vite, JavaScript (JSX), CSS3 |
| **Backend** | Python 3.12, FastAPI, Uvicorn, Pydantic, `aiohttp`, `requests` |
| **Архитектура** | Repository Pattern, Factory Pattern, Modular Routers |
| **Данные** | JSON (справочники), In-memory хранилище (готово к переходу на PostgreSQL) |
| **DevOps** | Docker, Docker Compose, Git |
