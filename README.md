# 🚀 Marketplace Migrator

Инструмент для автоматической миграции карточек товаров между маркетплейсами (Ozon → Wildberries). Позволяет селлерам экономить часы ручной работы, автоматически перенося названия, описания, цены, фотографии и intelligently маппя категории между разными площадками.

> 💡 **Особенность проекта**: Полностью функциональный MVP, который работает **без реальных API-ключей** благодаря умному Mock-режиму. Идеально для демонстрации архитектуры и логики.

---

## ✨ Основные возможности

- 📥 **Импорт с Ozon**: Получение данных о товарах через Ozon Seller API (или генерация реалистичных тестовых данных).
- 🧠 **Умный маппинг категорий**: Автоматическое преобразование категорий (например, Ozon *"Дом и сад / Уборка"* → WB *"Товары для дома"*) на основе локального справочника и эвристики.
- 📸 **Работа с медиа**: Сервис для скачивания фотографий товаров с генерацией заглушек для тестового режима.
- 📤 **Экспорт на Wildberries**: Формирование payload и отправка данных в формате, требуемом WB Content API (сейчас в Mock-режиме).
- 🎨 **Современный UI**: Интуитивно понятный интерфейс на React с подсказками, статусами операций и уведомлениями.
- 🐳 **Docker**: Полная контейнеризация для запуска одной командой в любом окружении.

## 🛠️ Технологический стек

| Слой | Технологии |
|------|------------|
| **Frontend** | React, Vite, JavaScript (JSX), CSS3 |
| **Backend** | Python 3.12, FastAPI, Uvicorn, Pydantic, `aiohttp`, `requests` |
| **Данные** | JSON (справочники), in-memory хранилище (готово к переходу на PostgreSQL) |
| **DevOps** | Docker, Docker Compose, Git |
